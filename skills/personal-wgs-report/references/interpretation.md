# 结果解读指南（写报告时查）

按报告章节排列。每节给：结果文件里看什么、阈值 / 规则、推荐措辞。措辞原则见 SKILL.md 第 5 步。

## 数据质量

- **原始深度 vs 有效深度**：测序公司说的 “30×” 是原始数据量 ÷ 3.1 Gb。去掉重复读段、低比对质量读段后，常染色体有效深度通常只有 18–25×。
  NovaSeq X / 6000 等图案化芯片的**光学（簇）重复**常占 10–25%，PCR 建库再加几个百分点。重复率 20–35% 在这类数据里常见，不算异常，但要说明“有效深度打了折”。
- 有效深度 <20× 时：单核苷酸变异基本不受影响；杂合插入缺失、低比例嵌合、结构变异、重复扩增、拷贝数的灵敏度下降——写进“局限”。
- 污染 FREEMIX ≥2%：杂合判断不可信，应先解决（重新取样 / 和测序公司核对）再出报告。VerifyBamID2 失败（日志里报错）时写“污染未能评估”。
- 推断性别（X/Y 相对深度：男 X≈0.5、Y≈0.5；女 X≈1、Y≈0）与自述不符：先核对样本，别继续写报告。
- 测序平台：读段名开头的仪器编号推测（LH=NovaSeq X 系列，A0=NovaSeq 6000……），只作参考。

## 小变异分级（findings.py 的规则）

| 分级 | 条件 |
|---|---|
| P/LP(ClinVar) | ClinVar 致病 / 可能致病，≥1 星且无冲突 |
| LP(预测功能缺失) | 人群频率 MAX_AF <0.5% 的无义 / 移码 / 经典剪接（±1–2）/ 起始丢失，不在逃逸 NMD 的末端（NMD 插件），且该基因致病机制是功能缺失（隐性 / X 连锁病基因，或 LOEUF<0.6 的显性病基因） |
| VUS-倾向致病 | MAX_AF <1% 的错义 REVEL ≥0.773 或 AlphaMissense likely_pathogenic，或 SpliceAI ≥0.5 |
| VUS | 其余罕见编码 / 剪接区变异（只在神经肌肉面板里列出） |

- `qc_note` 非空 = 读段层面可疑（杂合 VAF<0.30 或支持读段 <4、纯合 VAF<0.8、GQ<20、男性 X/Y 非 PAR 区不像半合子）：报告里要标“可信度低，需验证”，不要当确定结果写。
- “ClinVar 星级”：0 星 = 无评审依据；1 星 = 单个提交者有标准；2 星 = 多个提交者一致；3 星 = 专家组；4 星 = 实践指南。星级越低越要谨慎。
- “LP(预测功能缺失)” 不是 ClinVar 结论，是规则推断：措辞用“很可能破坏基因功能（软件预测，需临床实验室确认）”。
- VUS：意义未明，**绝大多数是良性的个人变异**；没有相关症状 / 家族史时不需要处理；数据库更新后可能改判。

### ACMG 次要发现（acmg_sf.tsv）
- ACMG SF v3.3 共 84 个“提前知道能改变管理”的基因。规则（assets/genelists/acmg_sf_v3.3.tsv 的 report 列）：
  `all` 任一 P/LP 即报告；`biallelic` 只有两个致病等位才算（单个杂合归入携带）；`HFE` 只报 p.C282Y 纯合；`TTN` 只报截短变异。
- 阳性的写法：基因、变异、疾病、外显率概念（“携带者一生中发病的概率明显高于普通人，但不是 100%”）、建议（临床实验室验证 → 遗传咨询 / 专科；按指南加强筛查；一级亲属可做针对性检测）。
- 阴性的写法：“在 84 个基因里没有发现致病或可能致病变异。这只说明没有查到已知的致病变异，不等于没有风险；家族史仍然重要。”

### 隐性携带（carrier.tsv / biallelic.tsv / pair.*）
- 人均携带 1–5 个隐性致病等位；对本人一般无影响。
- 两人联合分析（工作目录里恰好两个人）：`pair.shared_carrier.tsv` = 同一隐性基因两人都有致病等位 → 每胎 1/4 患病风险，建议遗传咨询（验证、讨论产前 / 胚胎植入前诊断）；
  `pair.partial_overlap.tsv` = 一方致病、另一方同基因有 VUS → 风险不确定，给专业人员评估。
- X 连锁：女性携带 → 每个儿子 50% 患病、每个女儿 50% 携带。男性 X 连锁致病变异（半合子）要看是否和表型相符。
- biallelic（同基因两个致病等位）：未定相，不知道是否在两条染色体上；结合本人有无相关表型判断是否需要就诊。

## 普通流程测不准的基因

- **SMN1 / SMN2**（SMNCopyNumberCaller）：SMN1=0 与 SMA 相符；SMN1=1 → SMA 携带者；SMN1≥2 → 大概率非携带，但“2+0”（同一条染色体两个拷贝、另一条 0 个）短读长分不出。中国人群携带率约 1/50。
- **α-地贫缺失**（hba_depth.py，读深法）：看 `call` 行。--SEA / -α3.7 / -α4.2 区段相对深度降到 ≈0.5 提示杂合缺失；阳性必须 gap-PCR 确认。华南高发。点突变型 α / β 地贫看携带表（HBA1/HBA2/HBB）。
- **GBA1**（Gauchian）：外显子 9–11 假基因样重组和其他变异；携带 → 戈谢病携带，且与帕金森病风险相关（只作提示）。
- **CYP2D6**（Cyrius）：见药物基因组一节；`*36+*10` 是东亚常见的串联结构。

## 重复扩增（str_summary.tsv + rfc1_motif.json）

- ExpansionHunter + stranger 目录（51 个位点：DM1/2、OPMD、NIID、OPDM、CANVAS、SCA27B、FAME、HD、多种 SCA 等）。`status` 为 normal / pre_mutation / full_mutation。
- 短读长对长于读长（150 bp）的重复只能给**下限 + 置信区间**；任何 pre / full mutation 都需要 RP-PCR / Southern / 长读长确认。
- **RFC1（CANVAS）必须看重复单元**：ExpansionHunter 用简并单元 (AARRG)ₙ 计数，分不清良性的 AAAAG / AAAGG 扩增和致病的 AAGGG / ACAGG 扩增，
  所以 RFC1 常被标成 full_mutation。看 `rfc1_motif.json` 的 `in_repeat_reads`：以“良性”单元为主 → 写“扩增的是常见良性单元，无临床意义”；以 AAGGG / ACAGG 为主 → 写“提示致病单元扩增，CANVAS 是隐性病，单个等位为携带；需确认”。
- 低深度（LowDepth 过滤）的位点结果不可靠。REViewer 读段图在 `work/<样本>/str/reviewer/`。

## 结构变异（<样本>.sv.tsv）

- 规则（sv_findings.py）：DEL/DUP、≤5 Mb、人群频率 <1%、断点不在缺口 / 黑名单、不全在片段重复区、不在 PAR；≥2 种方法支持；≥5 kb 需读深支持；
  临床相关 = AnnotSV ACMG 4/5、或缺失覆盖隐性 / X 连锁基因编码区（携带）、或缺失覆盖 ClinGen HI=3 基因、或重复完整覆盖 TS=3 基因。
- 每人软件报出几千到上万个 SV，几乎全是常见多态或伪影；报告级通常 0–2 个。报告级的建议用芯片 / MLPA / 长读长验证。复核级不要逐条写。

开头固定提醒：只在要用相关药物时才有意义；交给医生 / 药师；不要自己停药换药。完整建议见 PharmCAT HTML 报告。

- **CYP2D6 活性分**（CPIC）：*1、*2、*35、*39 = 1；*9、*14、*17、*29、*41、*49 = 0.5；*10 = 0.25；*3、*4、*5、*6、*13、*36、*52、*68 = 0；
  串联（如 `*36+*10`）各拷贝相加，`xN` 乘拷贝数。总分 0 = 慢代谢，0.25–1 = 中间，1.25–2.25 = 正常，>2.25 = 超快。
  PharmCAT 对 `*36+*10` 等串联可能报 “Undocumented … in outside call”，以 Cyrius 结果 + 手算活性分为准。
- **HLA 用药风险等位**（T1K 两位字段）：B*15:02（卡马西平 / 奥卡西平 / 苯妥英 SJS/TEN，汉族重要）、B*58:01（别嘌醇严重皮肤反应）、A*31:01（卡马西平 DRESS）、
  B*13:01（氨苯砜超敏，中国人群证据强；柳氮磺吡啶也需谨慎）、B*57:01（阿巴卡韦）、B*35:05（奈韦拉平）。携带就醒目提示“用这些药前告诉医生”；T1K 结果用于临床前仍应做专门 HLA 检测。
- **MT-RNR1**：m.1555A>G、m.1494C>T → 氨基糖苷类（庆大霉素、链霉素等）致聋风险，携带者及其母系亲属应避免。
- PharmCAT “Missing positions” 多的基因：结果不完整，写“部分位点未覆盖”。

## 多基因风险评分（prs）

- 百分位 = 参考人群（1000 Genomes 同一超级人群）里分数比你低的比例。只点评 ≥90 或 ≤10 的；20–80 写“处于人群中间”。
- 措辞：“第 95 百分位意味着基因背景比同族群 95% 的人偏高；风险大概相当于有一位一级亲属患病的水平（具体倍数因病而异），但大多数这个分数的人一生不会得这个病。”不要换算成个人患病概率。
- ≥90 百分位的常规建议（都是普通人也适用的筛查，只是更值得按时做）：前列腺癌 → 45–50 岁起和医生讨论 PSA；乳腺癌 → 按年龄做乳腺超声 / 钼靶，可讨论提前；
  结直肠癌 → 45–50 岁起肠镜或 FIT；LDL / 冠心病 / 卒中 → 定期查血脂血压血糖、戒烟；2 型糖尿病 → 控制体重、查空腹血糖 / HbA1c；高血压 → 测血压、控盐；
  痛风 → 查尿酸、少喝含糖饮料和酒；食管癌 → 少喝酒少吃烫食（ALDH2*2 携带者饮酒风险更高）；心房颤动 → 体检留意心律。
- 评分只用常染色体 SNV；`n_used / n_weights` 太低（<50%）时说明“评分位点覆盖不全，结果仅供参考”。

## 性状与单位点（traits）

- APOE（rs429358 + rs7412）：ε3/ε3 最常见，风险为人群平均；ε3/ε4 晚发阿尔茨海默病风险约 2–3 倍；ε4/ε4 约 8–12 倍（建议在遗传咨询下了解）；
  ε2/ε3 略低于平均（ε2/ε2 与 III 型高脂蛋白血症有关）。必加一句：“APOE 只影响概率，不能预测个人是否患病；控制血压血糖、运动、睡眠对所有人都适用。”
- ALDH2 rs671（A = *2）：携带者喝酒脸红、乙醛清除慢；常饮酒者食管鳞癌风险明显升高 → 写成“喝酒脸红是身体在报警”。
- MTHFR C677T：常被商业检测夸大；单独意义很小，不需要特殊补充剂。
- ABO：粗略推断（O = c.261delG 个数，B = rs8176746），未覆盖亚型，以血型检测为准。

## 祖源

- **somalier**：对照 1000 Genomes 判大洲（AFR/AMR/EAS/EUR/SAS），概率 >0.9 才写得肯定。
- **PCA**（pca_summary.json）：`nearest` = 投影后离哪些人群中心最近。写“和哪些现代人群最像”，不说“你是某某族”。
- **局部祖源**（LAI）：参考组是统计上的代表（如“北方型 = 北京汉族 CHB”），比例误差几个百分点；用留出的对照个体（lai_calibration 图）说明尺子的分辨率。
  每条染色体两行是两份拷贝，但跨染色体不对应同一位父母（未做家系定相）。
- **outgroup f3**：值越大 = 和该人群共享的遗传漂移越多；排名前几的置信区间常重叠 → “分不出高下”。古代人群样本少、位点少（nsnp 低）的不可靠。
- **qpAdm**：p ≥0.05 = 该混合模型“不能被拒绝”（可接受），不等于“证明”；比例估计看标准误。单个人做目标时误差远大于人群（看 results_indiv 的个体级对照），
  比例和对照人群差几个百分点没有意义。估计比例超出 0–100% 的模型不适用。
- **古人类片段**（hmmix）：非洲以外的人都有约 1–2% 尼安德特人 DNA（任一份拷贝合计常见 50–120 Mb），东亚人还有少量丹尼索瓦人成分。和对照比只说“在正常范围 / 偏多偏少”。
  落在著名渗入基因（如 SLC16A11、HYAL2、POU2F3、OAS 簇、HLA、KRT 等）的片段只做科普，不要暗示具体健康后果。
- **ROH**（≥1 Mb 纯合片段总长）：远亲婚配的后代也常有几十 Mb；一级表亲婚配后代平均约 180 Mb（基因组 1/16），二级表亲约 45 Mb；
  有几段 >10 Mb 的长片段更提示近亲。人群较小 / 较孤立的群体基线更高。只给数字和对照，不评判家庭。

## 母系 / 父系

- 线粒体单倍群（HaploGrep3，质量 >0.9 较可靠）；Y 单倍群（Yleaf：YFull / FTDNA / ISOGG 三套命名，名字不同但指同一分支）。只讲主干分布，不编迁徙故事。
- 线粒体已知致病位点：m.3243A>G（MELAS）、m.8344A>G（MERRF）、m.11778G>A / m.3460G>A / m.14484T>C（LHON）、m.8993T>G/C（NARP/Leigh）、m.1555A>G / m.1494C>T（氨基糖苷致聋）。
- 异质性：<5% 多为测序误差或核内线粒体假基因（NUMT）；poly-C 区（302–316、513–525、16180–16195）、3107 和插入缺失基本是伪影（collect_results.py 已排除）。

## 免疫与血液

- **HLA**：两位字段（如 A*02:01）。用途：移植配型（需专门检测）、用药风险（见上）、部分疾病关联（如 B*27 与强直性脊柱炎）——关联只是概率，写清楚“绝大多数携带者不发病”。
- **KIR**：A 单倍型基因（2DL1、2DL3、3DL1、2DS4）和 B 单倍型基因（2DS1/2/3/5、2DL2、2DL5、3DS1）；东亚人 AA 型很常见（约一半）。
- **红细胞血型**：Rh CcEe、Duffy、Kidd、Kell、MNS、Diego、Lewis、分泌型；RhD 阴性的东亚人有相当部分是 DEL 型（RHD c.1227G>A，血清学阴性但有少量 D 抗原）。均以血库检测为准。
- **未比对读段**（Kraken2）：“未能归类”多数是富含 GC 的细菌样序列或测序噪声；常见污染菌（慢生根瘤菌 Bradyrhizobium、鞘氨醇单胞菌等试剂盒菌）；
  人类序列（参考基因组未收录的版本）；病毒少量常见（细环病毒 TTV 大多数人血液里都有）。测不到 ≠ 没感染；测到常见病毒 ≠ 生病。

## 拷贝数会变的基因（cnv_genes）

- UGT2B17 两份都缺（0 拷贝）在东亚人里约占七八成：影响部分药物 / 激素代谢，无需处理。GSTM1 0 拷贝（null）约一半人：与解毒能力相关，单独意义小。
- AMY1（唾液淀粉酶）拷贝数个人差异大（2–20）：和饮食史有关，健康意义有限。
- LPA KIV-2 重复数和血 Lp(a) 水平**反相关**（重复少 → Lp(a) 往往高）：建议一生至少查一次 Lp(a)。
- 深度法只能给大概拷贝数，分不清在哪条染色体；临床判断需 MLPA / 长读长。

## 衰老相关指标（aging）

- 线粒体 DNA 拷贝数（WGS 血液常见 50–200 / 细胞）：受血细胞组成影响大，单次数值意义有限。
- Y 染色体丢失（LOY，男性）：Y/常染色体深度比 ≈0.5 为正常；估计丢失比例 >10% 才值得一提，与年龄、吸烟有关。
- 克隆性造血（CHIP）：30× 只能看到 VAF 较高的克隆；`germline_call=True` 的多是胚系杂合或伪影；真正的 CHIP 候选（DNMT3A、TET2、ASXL1 等热点，VAF 5–30%）也要血液专科深度测序确认。
- TelSeq 端粒长度：绝对值受建库、读长、平台影响大，只适合同一批数据内比较；不要和“端粒年龄”类商业检测对比。

## 基因组概览

- 一个人相对参考基因组约有 400–500 万个 SNV/插入缺失；其中 1000 Genomes 里没有的“新”变异几万个，大多数是个人 / 家族私有的良性变异。
- Ti/Tv、杂合 / 纯合比见“数据质量”。杂合度沿染色体的低谷可能对应 ROH。

## 局限（第九节必写，按实际情况取舍）

1. 短读长 WGS 测不准：FSHD（D4Z4 收缩）、重复扩增的精确长度、SMN1 “2+0” 沉默携带、高度同源基因（PMS2、CYP21A2、GBA1 的部分变异、HBA 的少见缺失）、平衡易位 / 倒位、DNA 甲基化。
2. 有效深度只有约 X×（见第一节）：杂合插入缺失、嵌合、结构变异、重复扩增的灵敏度低于真正的 30× 数据。
3. ClinVar、gnomAD 和致病性预测会更新；意义未明变异将来可能改判。可以隔一两年用新数据库重跑 10–11 步。
4. 多基因评分只反映相对高低，跨人群预测力差别大。
5. “没有发现” ≠ “没有风险”：只查了已知 / 高置信的致病变异；家族史仍然重要。
6. 结果没有经过临床实验室验证；任何用于诊疗、用药、生育决定的结果都要先验证并咨询医生 / 遗传咨询师。

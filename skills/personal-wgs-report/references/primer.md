# 科普素材：写报告时解释基本概念用

写报告时挑需要的段落改写，配上用户自己的数字（都在 summary.md 里）。不要整段照搬。

## 测序是怎么做的

- **从血到文库**：血液里只有白细胞有细胞核，DNA 从白细胞里提取。测序仪一次只能读一两百个碱基，所以先把 DNA 打碎成几百 bp 的片段，两端接上“接头”，做成由几亿个小片段组成的“文库”（超声打断、末端修复、加 A 尾、连接头、筛片段长度，多数还会 PCR 扩增）。
- **边合成边拍照（Illumina）**：文库铺到芯片（flow cell）上，每个片段原位扩增成几千份拷贝（一个“簇”），然后一轮轮加入带荧光、末端被封住的核苷酸，每轮每条链只接上一个，拍照后切掉荧光进入下一轮——每拍一轮读出一个碱基。
  NovaSeq X 只用两种颜色：只亮蓝 = A，只亮绿 = T，都亮 = C，都不亮 = G。华大 DNBSEQ 原理不同（DNA 纳米球），但输出一样。
- **双端测序（PE150）**：每个片段从两头各读 150 个碱基，所以读段是成对的；两端之间的距离 = 片段长度（插入片段），中位数通常 300–400 bp。
- **质量值 Q**：Q = −10 × log₁₀(读错的概率)。Q20 = 百分之一、Q30 = 千分之一、Q40 = 万分之一。“Q30 比例 95%” = 95% 的碱基读错概率低于千分之一。
- **深度**：数据量 ÷ 基因组大小（约 3.1 Gb）= 平均每个位置被读几遍。读段随机落在基因组上，有的地方多有的地方少；一个位置只读到三四次，可能恰好都来自同一份拷贝，杂合变异就漏了——所以要读 20–30 遍。
- **重复读段**：同一个 DNA 分子被读了不止一次（PCR 扩增出的多份拷贝、或芯片上相邻孔“串”了同一个分子 = 光学重复）。不提供新信息，分析时每组只留一条，所以“有效深度”比原始深度低。
- **性别和线粒体**：男性只有一条 X，X 的深度约为常染色体的一半；每个细胞有上百份线粒体 DNA，所以线粒体深度高达上千 ×。

## 数据格式

- **FASTQ**（测序公司交付的原始数据，*.fq.gz）：每条读段 4 行——名字、碱基、加号、每个碱基的质量。名字里有仪器编号、芯片、泳道和坐标。一个 30× 的人大约 2 个文件、共 30–50 GB。
- **BAM / CRAM**：比对以后，每条读段多了一个“地址”（哪条染色体第几个碱基、正向还是反向、比得好不好），按位置排序、建索引，就能像查地图一样调出任意一段。把覆盖同一位置的读段叠起来就是“读段堆叠”。
- **VCF**：只记“和参考基因组不一样的地方”：每行一个位点，前面是位置和碱基，最后一列是你的基因型和证据（深度、质量）。一个人约 400–500 万个变异，完全正常——参考基因组本身只是少数几个人的 DNA 拼出来的。
- **gVCF**：比 VCF 多记了“哪些位置确认和参考一样”，和别人的数据一起分析、或判断“这个位置到底是没测到还是没变异”时要用。
- 体积：FASTQ ≈ BAM（几十 GB）≫ VCF（约 0.1 GB）。原始数据（FASTQ 或 BAM）值得长期保留：将来方法和数据库更新了可以重新分析。

## 分析的原理

- **比对**：给每条读段在参考基因组（GRCh38）上找位置。BWA-MEM 先用索引快速找到完全匹配的“种子”，再在附近做精细比对，容许错配和小的插入缺失。比不上的读段（通常 0.1–0.5%）大多不是人的 DNA（污染菌、病毒）或参考基因组没收录的人类序列。
- **找变异**：DeepVariant 把每个候选位点的读段堆叠画成一张多通道“图片”（碱基、质量、链方向……），用识别照片的卷积神经网络判断是纯合参考 / 杂合 / 纯合变异。多人一起分析时用 GLnexus 合并各人的 gVCF，在同一位置用同一标准判断。
- **注释**：这个变异在哪个基因里、改不改变氨基酸（同义 / 错义 / 无义 / 移码 / 剪接）、在人群中多常见（gnomAD）、有没有被报告过致病（ClinVar）、预测工具怎么打分（错义看 REVEL、AlphaMissense，剪接看 SpliceAI）。
- **筛选**：几百万个变异里，绝大多数在基因之间或内含子里、或者在人群里很常见。只留“落在基因上、可能改变蛋白或剪接、人群里罕见”的，再按规则分级（见 interpretation.md），最后剩几十个需要人来看。
- **ACMG / AMP 分级**：致病（P）、可能致病（LP）、意义未明（VUS）、可能良性（LB）、良性（B）。本流程只做自动化的简化分级，正式分级需要临床实验室结合文献和家系。

## 各类分析一句话原理

| 分析 | 想回答 | 原理 | 工具 |
|---|---|---|---|
| 祖源 PCA | 和哪些现代人群最像 | 几十万个常见位点上的等位基因频率差异压缩成几个主成分，人群按亲缘远近分开 | plink2、smartpca |
| outgroup f3 / qpAdm | 和哪些古代人群最近、由哪些祖先成分混合 | 相近的人群共享更多“遗传漂移”；用一组外群检验混合模型是否成立 | ADMIXTOOLS、AADR |
| 局部祖源 | 每一段染色体像哪个参考人群 | 先把两份拷贝分开（定相），再沿染色体逐段和参考单倍型比 | Beagle、RFMix |
| 古人类片段 | 身上有多少尼安德特人 / 丹尼索瓦人 DNA | 找“非洲人里没有、又成片出现”的衍生变异，再和古人类基因组比对 | hmmix |
| 纯合片段 ROH | 父母有没有血缘关系 | 找两份拷贝完全相同的长片段：父母越近，长片段越多 | bcftools roh |
| 单倍群 | 父系 / 母系属于哪一支 | 把 Y 染色体 / 线粒体的变异放到人类系统树上 | Yleaf、HaploGrep3 |
| 重复扩增 | 有没有致病的重复扩增 | 数跨过重复区的读段里有几个重复单元；超长时只能估下限 | ExpansionHunter |
| 难测基因 | SMA、CYP2D6、GBA1、α-地贫 | 和假基因高度相似，普通流程会比错；专门的工具按深度和区分位点计数 | SMNCopyNumberCaller、Cyrius、Gauchian |
| HLA / KIR | 免疫“身份证”和“读卡器” | 读段和已知等位基因序列库逐一比对 | T1K |
| 药物基因组 | 药物代谢快慢、过敏风险 | 关键位点组合成星号等位（*1、*2…）→ 表型 → 按 CPIC / DPWG 指南给建议 | PharmCAT |
| 多基因风险 | 某种病的“基因背景”高不高 | 成百上千个小效应变异加权求和，再和同人群比百分位 | PGS Catalog、plink2 |
| 拷贝数 | 哪些基因多一份、少一份 | 某段的深度 ÷ 全基因组平均深度 × 2 | CNVpytor、深度脚本 |
| 结构变异 | 大片段缺失 / 重复 / 倒位 | 读对距离异常、读段被劈开、深度变化，多种方法互相印证 | Manta、Delly、AnnotSV |
| 未比对读段 | 血液里有没有病毒 / 细菌 DNA | 比不上人类参考的读段，按 k-mer 和微生物数据库匹配 | Kraken2 |
